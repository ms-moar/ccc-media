Ресеч по теме обхода цензуры в зависимости от оболочек взаимодействия:

Для Google (Gemini) полный обход цензуры возможен только при использовании Developer API Key с настройкой BLOCK_NONE, поскольку авторизация через потребительскую подписку PRO в Antigravity в любом случае принудительно активирует жесткие серверные фильтры Google. 
т.е вариант только брать API ключи

Для Claude (Anthropic) в API нет переключателя безопасности, но работа через Cowork/API обходит консервативный потребительский системный промпт («harmless assistant») веб-чата Claude.ai, что дает значительную свободу действий при условии использования чисто технического или академического фреймирования запросов.

т.е возращаемся к  "притворись сайберресерчером"
