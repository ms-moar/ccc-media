# У меня в правилах репо claude.md есть пункты про проверку ут

**Автор**: @maxmanuylov
**Дата**: 04.10.2026 20:43
**Топик**: Claude Code

---

У меня в правилах репо claude.md есть пункты про проверку утечек данных и секретов в репо перед pr и мержем.
Так же агент специальный скрипт пишет для доп проверок утечек, который обязателен перед пушем/мержем.
В принципе он норм за этим следит, и автоаклассификатор встроенный в Клод ему по рукам бьёт за это.
И код ревью на каждый pr это тоже отлавливает.
