1. 🔀 LiteLLM — умный роутер запросов

Кто: Moe Khalil, Product Engineer @ LiteLLM (бенчмарк опубликован 20.09)

Задача: Роутить входящие запросы по тирам (SIMPLE / MEDIUM / COMPLEX / REASONING). Раньше делал Claude Haiku.

Паттерн: Jev получает raw-запрос → возвращает typed Choice → только потом вызывается нужная модель.

| Метрика | Jev | Haiku |
|---------|-----|-------|
| Latency p50 | 126 ms | 688 ms |
| Latency p95 | 231 ms | 897 ms |
| Стоимость / 240 вызовов | $0.008 | $0.199 |
| Точность классификации | 95% | 73.75% |

→ 5x быстрее, 96% дешевле, точнее. Источник

2. 📄 Every.to — ре-ранкинг RAG перед LLM

Задача: В legal-RAG-пайплайне Jev скорит каждый кандидат-фрагмент на релевантность ДО инжекта в контекст. Второй Jev (Noul) — детектит prompt-injection в retrieved-контенте (planted attack → 0.99 confidence).

Цифры:
- 777 passages judged за 0.7 секунды — vs 8.83 с при LLM-judge
- Стоимость батча: $0.0025 (четверть цента)
- Top-1 accuracy: 5% → 18%; Top-10: 38% → 62%

→ Jev как "фильтр качества" перед дорогим контекстным окном. Источник

3. 🛡️ pi-warden / LangChain — safety gate для агентов

Кто: Open-source проект + официальная интеграция LangChain.

Задача: Coding/browser агенты делают деструктивные tool calls (bash, rm, API writes) без проверки. LLM-guard слишком медленный.

Паттерн: Перед каждым вызовом инструмента → Jev проверяет по rule-файлу → возвращает ALLOW / HOLD / BLOCK с вероятностью. Агент продолжает только при ALLOW выше порога.

Цифры: 42 блокировки на 17,000 зафиксированных вызовов, ~88% из них корректны post-hoc. Kyle Jeong (Browserbase): агент работает "за доли цента". Источник

4. ☕ Spring AI — quality-gate loop в Java продакшне

Задача: Гарджейлы, jailbreak detection, проверка качества вывода — без второго LLM-вызова.

3 паттерна:
- JevSelfRefineAdvisor — Jev скорит черновик LLM, если фейл → LLM ретраит с нарушением в контексте
- JevGuardrailAdvisor — скрин входящего промпта (jailbreak block до вызова LLM) + скрин выходного ответа
- JevDocumentReranker — фильтр RAG-пассажей

Цифры: 14 вопросов Jev → 275–310 ms vs 1.8–14 с для LLM-аналогов. Стоимость: $0.000043 за батч из 14 вопросов. Источник

5. 📈 Трейдинг-боты — решение на каждый тик

Кто: Jev Trade (Hyperliquid), Jev Trader (Monad/Kuru), QuantDinger.

Задача: Algo-трейдинг требует sub-second решений на каждый маркет-тик. LLM (3–30 сек) — нереально. Rule-based системы не улавливают нюанс.

Паттерн: Per tick → сериализовать market state → Jev возвращает long/short/hold, open/close, leverage → код ставит ордер.

Ключевой инсайт: QuantDinger использует calibrated confidence score как audit trail — это то, что LLM принципиально не умеет. 70–500 ms делает per-tick feasible. Источник

Три главных паттерна интеграции

1. LLM pre-filter/router  →  Jev классифицирует сложность, роутит
2. Agent safety gate      →  Jev чекает tool calls перед выполнением
3. RAG re-ranker          →  Jev скорит passages до инжекта в контекст

Killer-фича: calibrated confidence score — не просто решение, а вероятность с аудит-треилом. LLM это не может.
