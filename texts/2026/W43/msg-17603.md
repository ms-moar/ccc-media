Пять уязвимостей в двух пакетах. 

В qmd оба пакета попадают не напрямую, а через другие библиотеки.

simple-git — четыре уязвимости

Это библиотека, через которую Node-код вызывает git. У неё есть защита: она не даёт передать в git опасные параметры, которые позволяют запустить произвольную команду. Все четыре уязвимости — способы обойти эту защиту:

GHSA: GHSA-x6jw-m9v5-85vh
уровень: critical
в чём суть: защита не блокирует настройку git trailer с командой
внутри — git её выполнит
────────────────────────────────────────
GHSA: GHSA-v5rq-49vh-5v5c
уровень: critical
в чём суть: переменная VISUAL (какой редактор открыть) не считается
опасной, хотя через неё git запускает любую программу
────────────────────────────────────────
GHSA: GHSA-g4wm-2vf7-vfgr
уровень: high
в чём суть: через include в конфиге git можно подтянуть чужой
конфиг с командой
────────────────────────────────────────
GHSA: GHSA-858h-whjf-mvg5
уровень: high
в чём суть: сокращённые опции (--receive-p вместо --receive-pack,
--exe вместо --exec) проходят мимо проверки и запускают команду;
это недозакрытая старая CVE-2026-28291

Общее у всех четырёх: опасно, только если аргументы для git приходят от постороннего. 

Например, если сервис берёт URL или опции из запроса пользователя и отдаёт их в simple-git.
