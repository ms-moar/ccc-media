бот говорит что так: 

Через официальный плагин telegram для Claude Code. По шагам:

0) Нужен Bun — на нём крутится MCP-сервер плагина: curl -fsSL https://bun.sh/install | bash

1) Создать бота у @BotFather: /newbot → имя и юзернейм (должен заканчиваться на bot). Он выдаст токен вида 123456789:AAH… — копировать целиком, с цифрами и двоеточием.

2) В сессии Claude Code: /plugin install telegram@claude-plugins-official

3) Отдать токен: /telegram:configure 123456789:AAH…
Он запишет его в ~/.claude/channels/telegram/.env

4) Перезапустить сессию с флагом канала — без него сервер не поднимется:
claude --channels plugin:telegram@claude-plugins-official

5) Спарить: написать боту в личку, он ответит 6-значным кодом, и в сессии Claude Code выполнить /telegram:access pair <код>. После этого личка доходит до ассистента.

Если нужно, чтобы отвечал в группе, а не только в личке:
• /telegram:access group add -100…  (id супергруппы, отрицательный, в интерфейсе Telegram не показывается — проще всего добавить в группу @RawDataBot на минуту, он выдаст id)
• по умолчанию бот реагирует только на @упоминание или ответ на его сообщение. Если хочется, чтобы читал все сообщения — флаг --no-mention, и обязательно у @BotFather /setprivacy → Disable, иначе Telegram просто не отдаст боту эти сообщения.

Две грабли из нашего опыта: сессия должна жить постоянно (мы держим в tmux — закрыл терминал, бот замолчал), и после автообновления плагина стоит проверить, что канал поднялся, а не отвалился молча.
