# Сейчас это выглядит как реальный и довольно серьёзный инциде

**Автор**: @pionerio
**Дата**: 20.05.2026 13:26
**Топик**: General

---

Сейчас это выглядит как реальный и довольно серьёзный инцидент у  GitHub, а не фейк или слух.

Главное по ситуации:

GitHub подтвердил компрометацию примерно **3 800 внутренних репозиториев**.  
По предварительным данным, входной точкой стал **компрометированный VS Code extension** (“poisoned extension”), установленный сотрудником GitHub.  
Атаку связывают с группой **TeamPCP**, которая в последние месяцы активно проводит supply-chain атаки на open-source экосистему.  
GitHub заявляет, что:
заражённое устройство изолировано,
extension удалён,
идёт ротация секретов и анализ логов,
пока нет признаков продолжающегося доступа злоумышленников.  

Что особенно важно:

Речь идёт не о массовом взломе пользовательских private repo напрямую.
Но есть риск утечки:
внутренних GitHub инструментов,
CI/CD логики,
токенов,
интеграций,
supply-chain компонентов.  

На фоне этого уже всплывают связанные supply-chain кейсы:

компрометация GitHub Actions,
вредоносные npm-пакеты,
заражённые VS Code extensions,
утечки токенов разработчиков.  

Что тебе стоит сделать прямо сейчас, если у тебя есть активные GitHub/CI проекты:

Проверить и ротировать:
GitHub PAT tokens,
SSH keys,
GitHub Actions secrets,
npm tokens,
cloud credentials.
Проверить:
недавно установленные VS Code extensions,
особенно малоизвестные или недавно обновлённые.
Просмотреть:
GitHub OAuth Apps,
GitHub Apps,
suspicious Actions runs.
Включить/проверить:
mandatory 2FA,
fine-grained PAT,
secret scanning,
Dependabot alerts.
Если используешь self-hosted runners:
считать их потенциально скомпрометированными до проверки.
