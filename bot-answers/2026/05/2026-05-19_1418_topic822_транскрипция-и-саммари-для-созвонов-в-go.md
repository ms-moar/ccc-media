## Вопрос

транскрипция и саммари для созвонов в Google Meet или Jitsi Meet? какие есть решения, подходы? как реализовать бесплатно или через готовый сервис?

## Ответ

Вот что есть в базе знаний группы по транскрипции и саммари созвонов:

**Fathom — ИИ-помощник для митингов**

Самое обсуждаемое решение. Fathom автоматически записывает аудио звонков в Google Meet, создаёт транскрипты и сохраняет все встречи в базу.

По данным @tommypoltev (09.04, топик "кейсы"): он использует Fathom на всех командных и 1:1 митингах в Google Meet. Транскрипты передаёт через API в своего OpenClaw помощника, который пишет самари, to do list и отслеживает динамику задач. Например, на еженедельных 1:1 с СМО помощник уже знает контекст звонков за 4 недели и подсвечивает: "вот это делают давно и нет результата, а это обсуждали в первую неделю и потом из повестки пропало". Перед звонком можно спросить "какие вопросы задать, на что обратить внимание" — и он хорошо подсвечивает забытые штуки.

По данным @pavel2077 (в обсуждении от 14.04): он тоже использует этот подход — Краб (OpenClaw) берёт экшн айтемы в таски и легко вернуться к контексту разговоров.

Ссылка на сервис: https://fathom.video
Ссылка на кейс @tommypoltev: https://t.me/c/3602915633/2936/8821
Ссылка на обсуждение: https://t.me/c/3602915633/822/9122

**Groq — бесплатный Whisper API**

По данным @samaye10 (10.03): Groq предоставляет бесплатный доступ к Whisper API — до 8 часов аудио в день без оплаты. Работает быстрее локального запуска. @sklip подтвердил что сервис топ.

Ссылка: https://t.me/c/3602915633/822/5476

**Whisper — локальное распознавание**

По данным @tommypoltev (10.03): Whisper от OpenAI работает полностью локально, бесплатно. OpenClaw сам скачал и установил Whisper после первого голосового — даже не спрашивал (кейс от @cpacash). Модель ~140MB, с PyTorch ~5GB.

По данным @pavel2077 (18.02): в OpenClaw есть скилл, который автоматически скачивает и ставит Whisper для транскрипции аудио.

Ссылка: https://t.me/c/3602915633/822/5481

**ffmpeg + Gemini 2.5 Flash**

По данным @tommypoltev (28.02): для любых видео/аудио — ffmpeg извлекает аудио, Gemini Flash делает транскрипт. Бесплатно.

**VAPI — голосовые сервисы для звонков**

По данным @pavel2077 (18.03): поднимал вопрос интеграции VAPI для автоматического приёма звонков. Если нужна не только транскрипция, но и полноценный голосовой бот.

Ссылка: https://t.me/c/3602915633/822/6209

**Итого по подходам:**

1. Готовый сервис (Fathom) — самый простой вариант для Google Meet, есть бесплатная версия, API для интеграции с агентами
2. Whisper через Groq — бесплатно до 8ч/день, если нужен кастомный пайплайн
3. Whisper локально — полностью бесплатно, без лимитов, но нужен свой сервер
4. ffmpeg + Gemini Flash — для кастомных решений с любым источником аудио

По Jitsi Meet конкретных кейсов в базе знаний не нашлось — все обсуждения крутятся вокруг Google Meet.
