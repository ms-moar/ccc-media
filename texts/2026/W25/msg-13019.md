# Небольшой кейс, как Claude Code вырвал из лап вендорлока Aut

**Автор**: @maxmanuylov
**Дата**: 16.06.2026 23:17
**Топик**: Кейсы

---

Небольшой кейс, как Claude Code вырвал из лап вендорлока Authy мои ключи для генерации OTP кодов. Возможно кому-то тоже пригодится.

Они довольно давно прибили десктоп приложение, выпилили экспорт и закрыли возможность дёргать коды через Raycast extension, оставив только мобильное приложение.

Единственный способ переехать на другое приложение для 2fa - это в каждом сервисе перевыпускать ключи, что геморно и лишний триггер на security check.

Поручил Клоду найти решение как выдрать ключи из iOS приложения. 

Он поднял MITM-proxy, рассказал как всё настроить на iPhone, дал задачу что настроить в приле, перелогиниться и перехватил всю базу ключей 😀
