# Обратите внимание, СС может ссылаться вместо конкретного бло

**Автор**: @pionerio
**Дата**: 18.09.2026 16:59
**Топик**: Claude Code

---

Обратите внимание, СС может ссылаться вместо конкретного блока на строки в любом файле при изменение которого, ссылка перестанет работать или он будет ее постоянно переписывать.

В моём собственном системном промпте этой сессии, раздел # Harness, стоит ровно одна строка про ссылки:

▎ Reference code as file_path:line_number — it's clickable.

Безусловная, без области действия и с обоснованием «кликабельно» — то есть про терминал оператора, а не про файл, который читает модель. Модель читает её буквально и применяет везде, в том числе когда пишет правило или скилл. Это и есть канал, по которому баг зашёл в систему.
