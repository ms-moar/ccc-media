# кстати не так давно в cc cli добавили возможность отслеживат

**Автор**: @maxmanuylov
**Дата**: 22.09.2026 22:47
**Топик**: Claude Code

---

кстати не так давно в cc cli добавили возможность отслеживать состояние кэша если кто пропустил, можно выводить инфу в statusline

В Claude Code (2.1.251+, причины промахов с 2.1.260) в статуслайн теперь приходит объект prompt_cache: доля попаданий в кэш, число промахов, время остывания кэша (expires_at) и вероятная причина последнего промаха (изменились tools или system prompt, истёк TTL, серверная). Если добавить в statusLine поле "refreshInterval": 30, скрипт будет обновляться и в простое. Так видно, что кэш вот-вот остынет или уже остыл и следующее сообщение заново закэширует весь контекст. Те же данные есть в /cost. Документация: https://code.claude.com/docs/en/statusline#prompt-cache-fields
