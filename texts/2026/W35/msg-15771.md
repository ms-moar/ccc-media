Понятно! Тогда коротко механика:

1. Claude Code поддерживает флаг `--append-system-prompt-file <path>` — он **добавляет** содержимое файла к дефолтному системному промпту (не заменяет его).
2. Автор просто написал markdown-файл с явными инструкциями "не делай так / делай так" + список конкретных запрещённых фраз/паттернов.
3. Через `justfile` (`just sr-opus`) это автоматически прокидывается в каждый запуск `claude`, так что правило действует на всю сессию, а не на один промпт.

По сути никакой магии — это просто грамотно составленный prompt engineering, который эксплуатирует тот факт, что system prompt весит больше и живёт дольше, чем один user prompt. Никакого дообучения модели или API-хаков, чистый текст в системном промпте.
