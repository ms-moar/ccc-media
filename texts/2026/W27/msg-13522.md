**Як зробити Paperclip як окрему Mac app**

Якщо Paperclip уже працює локально і відкривається тут:
http://127.0.0.1:3100
то можна зробити з нього окрему macOS app через Chrome.

Це буде не .dmg, а **Chrome App / PWA app bundle**, така сама логіка як:
~/Applications/Chrome Apps.localized/Paperclip.app
**Як створити**

1. Відкрити у **Google Chrome**:
http://127.0.0.1:3100
2. У Chrome натиснути меню ⋮.

3. Обрати один із варіантів, залежно від версії Chrome:
Save and share → Create shortcut…
або:
More Tools → Create Shortcut…
або якщо є кнопка install:
Install Paperclip…
4. Назвати:
Paperclip
5. Обовʼязково увімкнути:
Open as window
6. Натиснути **Create**.

Після цього зʼявиться окрема Mac app:
~/Applications/Chrome Apps.localized/Paperclip.app
Її можна запускати через Spotlight / Launchpad / Dock як звичайну програму.

**Що це таке технічно**

Це маленька Chrome-generated app, яка відкриває:
http://127.0.0.1:3100/
Всередині вона використовує Chrome app_mode_loader, тому macOS бачить її як окрему апку.
