# Готово. Переключил Coding Bro с CLI на прямой OAuth-to-API.

**Автор**: @y_tgam
**Дата**: 30.06.2026 16:15
**Топик**: OpenClaw

---

Готово. Переключил Coding Bro с CLI на прямой OAuth-to-API.

**Что сделал:**

• В agents.list[] для добавил per-agent оверрайд рантайма:
"models": {
  "anthropic/claude-opus-4-8": {
    "agentRuntime": { "id": "openclaw" }
  }
}
• Это переопределяет **толькоCoding Bro**. Main и ops остаются на claude-cli (через бинарь claude -p) — не тронуты.
• JSON провалидировал, бэкап главного конфига сделал (openclaw.json.bak-20260630-125346).

**Что это значит технически:**

• Было: opus 4-8 исполнялся через claude-cli рантайм (запуск локального бинаря claude -p).
• Стало: openclaw embedded рантайм бьёт напрямую в api.anthropic.com, авторизуясь теми же OAuth-кредами подписки. То есть «opus через OAuth, без CLI» — ровно как ты просил.
